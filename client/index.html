MirageAPI — Instant mock servers from any OpenAPI spec

Upload or paste an OpenAPI 2.0, 3.0 or 3.1 spec (JSON or YAML) and every endpoint is live immediately, returning fresh, realistic dummy data on every request. No signup, no install.

Features

  • Constraint-aware data: respects types, formats (email, uuid, date-time), minLength/maxLength, minimum/maximum, pattern and enum
  • Nested objects and arrays generated recursively
  • Built-in spec validation with clear error messages
  • Request tester and endpoint explorer in the browser
  • Open-source CLI: node src/index.js --spec ./openapi.yaml --port 3000
